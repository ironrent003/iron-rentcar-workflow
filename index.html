회사소개서로 이해하는 아이언렌트카

회사 전체 사업영역과 신규입사자 교육 범위를 구분해 확인합니다.

신규입사자 교육 핵심 범위구독렌탈차량관리장기렌터카 운영기준은 렌탈 업무의 공통·부서별 기준으로 반영했습니다. 사고대차·중고차 수출·법무·채권은 회사 및 협업 참고 영역입니다.

MISSION & VALUES

이동의 자유를 넘어, 새로운 모빌리티 경험을 디자인합니다.

“당신의 여정이 시작되는 곳”

아이언렌트카는 단순히 차량을 빌려주는 서비스를 넘어 고객의 소중한 여정을 안전하게 지탱하는 모빌리티 파트너를 지향합니다. 변치 않는 신뢰, 철저한 차량관리, 정직한 서비스를 업무의 기준으로 삼습니다.

✅승인 기준

특별할인·비표준 조건·선발주·초기 납부금 미입금 출고·위약금 감면·채권 감면·시동제어·계약해지·강제회수는 정해진 승인체계를 확인합니다.

🔐보호·인수 기준

신분·연락처·계좌·신용·면허·차량 위치·계약자료는 업무 목적 범위에서만 이용하고, 인수자료가 부족하면 보완 전 법적 조치를 보류합니다.

표준 13단계: 상담 접수 → 차량·조건 확인 → 견적·심사 → 재고·발주 → 전자약정·계약 → 초기 납부·등록·보험 → 출고·인도 → 에이전트 수수료 요청 → 수납·유지관리 → 연체·민원 → 연장·해지 → 반납·회수 → 최종 정산·채권 인계·추심·종결

계약서 작성 시 운전자격·연령 필수 확인

영업팀과 고객관리팀은 계약서 작성 및 모렌 등록 전에 아래 항목을 모두 확인하고, 확인 결과를 계약자료에 남겨야 합니다.

운전자격운전면허 취득 후 1년 이상인지 확인
운전자 연령보험 적용 연령 기준이 21세인지 26세인지 등 해당 조건 확인

특히 운전자 연령은 사고 발생 시 보험 적용 여부가 결정될 수 있으므로, 추정하지 말고 보험조건·계약조건·에이전트별 조건을 반드시 대조한 뒤 계약을 진행합니다.

연체 발생 시 약정 기준에 따른 단계별 조치

공통 운영기준상 고정 일수는 없으며, 계약·약정서·약관 및 에이전트별 조건을 우선 적용합니다.

🔎 연체 발생 약정 조건 확인

입금 미확인 시 계약번호·에이전트·약정서·연체일수와 기준일을 확인합니다.

🔒 예: 약정 기준 3일 초과 시동제어

해당 계약에 시동제어 조항이 있고 기준일을 초과한 경우 정해진 절차에 따라 조치합니다.

📄 예: 약정 기준 7일 초과 계약해지 가능 검토

해지 조건·통지·회수·정산 기준을 확인한 뒤 계약해지 가능 여부와 후속 조치를 검토합니다.

🤝 에이전트별 조건 상이 해당 약정 우선 적용

3일·7일을 일률적으로 적용하지 않고 에이전트별 계약조건과 내부 승인 기준을 적용합니다.

중요 공통 운영기준에는 모든 계약에 동일하게 적용하는 연체 일수가 정해져 있지 않습니다. 3일·7일은 예시 기준이며, 실제 시동제어·계약해지·차량회수 조치는 해당 계약서·약관·에이전트별 조건과 내부 승인을 확인한 뒤 정해진 기간을 초과한 경우에만 실행합니다.
  1. 연체일수의 기준일(납부기한, 영업일/달력일 등)과 계약상 불이익 조건을 약정서에서 확인합니다.
  2. 조치 전 고객·에이전트 연락, 납부 약속, 안내·통지 및 내부 승인 이력을 남깁니다.
  3. 시동제어 전 계약·약관 근거, 연체금액·기간, 차량 위치·운행상태, 안전한 장소 여부를 확인합니다.
  4. 운행 중·위험지역·응급상황·납부완료 미확인·내부 승인 없는 경우에는 시동제어를 진행하지 않습니다.
  5. 조치 후에도 미수금·차량 상태·회수·법무 이관 여부를 계약번호 기준으로 기록합니다.

신규입사자 업무 인수·마감 체크

어떤 문의를 받든 아래 항목을 계약번호 기준으로 확인하고 기록하세요.

🧑‍🤝‍🧑① 누구의 건인가?

고객·에이전트·계약번호·담당자를 확인합니다.

🚘② 어떤 차량인가?

차량번호·상태값·출고일·현재 위치를 확인합니다.

🪙③ 어떤 금액인가?

월 대여료·보증금·미수금·정산금의 기준일을 확인합니다.

🗒️④ 무엇을 기록했나?

상담·견적변경·납부약속·민원·조치·통지 이력을 남깁니다.

✅⑤ 승인이 필요한가?

특별할인·비표준 조건·감면·시동제어·해지·회수 승인 여부를 확인합니다.

📮⑥ 누구에게 넘길 건가?
