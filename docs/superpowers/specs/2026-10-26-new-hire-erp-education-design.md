# 신입직원 ERP 업무흐름 교육자료 확장 설계

## 의도

기존의 클릭형 7단계 업무흐름도를 유지하면서, 신입직원이 각 단계의 차량·계약·금액·부서 인계를 이해하도록 확장한다.

## 대상과 범위

- 대상: 아이언렌트카 신규입사자
- 기본 흐름: 문의 접수 → 계약 진행 → 차량 준비 → 차량 출고 → 이용 중 관리 → 반납/연장 → 정산/종료
- 부서 표기: 영업팀, 고객관리팀, 경영관리, 법무팀(법무·채권관리)
- 교육용 설명만 다룬다. ERP 코드 구조, Docker, 연동 구현 방식은 표시하지 않는다.

## 화면 구성

- 기존 탭과 7단계 카드, 접힌 상세 카드, 인쇄/PDF 대응을 유지한다.
- `교육 흐름` 탭에는 계약·차량·금액의 연결과 표준 인계정보를 추가한다.
- `차량관리` 탭에는 차량 준비 상태와 계약 배정 상태를 분리해 나란히 설명하고, 반납 후 재렌트·매각까지 연결한다.
- `역할·협업` 탭에는 사고, 운행위반, 청구·수납·연체, 예외 승인과 부서별 인계 기준을 추가한다.

## 교육 원칙

- 계약은 차량 준비, 운행, 청구, 반납, 매각을 잇는 기준점으로 설명한다.
- 업무 처리와 금액 관리는 구분한다. 청구·수납·원장은 경영관리 확인 항목으로 다룬다.
- 차량 준비 상태와 계약 배정 상태는 별도로 표기한다.
- 신입사원이 단독 결정하면 안 되는 사항에는 승인·법무·경영관리 확인 안내를 넣는다.
- 인계 완료는 다음 담당자가 계약번호와 차량번호만으로 현재 상태, 금액, 남은 조치, 다음 일정을 파악할 수 있는 상태로 정의한다.

## 포함할 신규 상세 항목

1. 계약·차량·금액을 나눠 보는 실무 기준
2. 차량 준비상태와 계약 배정상태의 병렬 흐름
3. 사고 접수부터 수리·청구 또는 손익 반영까지의 흐름
4. 운행위반 고지서와 문서24 운전자변경의 기본 흐름
5. 청구·수납·충당·미납·연체·법무의 연결
6. 반납점검 후 재상품화·재렌트·매각의 분기
7. 인계 완료 기준과 단독 판단 금지 항목

## 제약

- 외부 라이브러리 없이 동작한다.
- 모바일과 인쇄 레이아웃을 유지한다.
- 기존 상세 내용과 중복되는 설명은 확장하거나 보완하는 방식으로 통합한다.
